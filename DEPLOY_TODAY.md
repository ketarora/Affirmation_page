## 📱 APP STORE SUBMISSION

### Google Play Console (Android)

**Time:** 30 minutes setup + 2-4 hours review

1. Go to: https://play.google.com/console
2. Create new app or select existing
3. Upload file: `build/app/outputs/bundle/release/app-release.aab`
4. Fill in:
   - App description
   - Screenshots (5-8 images)
   - Category: Lifestyle/Wellness
   - Content rating
   - Privacy policy (add any URL or text)
5. Submit for review ✓

**Status:** Usually approved within 2-4 hours

### Apple App Store (iOS)

**Time:** 30 minutes setup + 24-48 hours review

1. Go to: https://appstoreconnect.apple.com
2. Create new app or select existing
3. Upload IPA via Xcode (requires Mac):
   ```
   xcode-select --install
   cd <project>
   flutter build ios --release
   ```
4. Fill in same information as Android
5. Submit for review ✓

**Status:** Usually approved within 24-48 hours
